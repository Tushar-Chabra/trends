    Pehli baar aaye? 30 second ki guide (kholne ke liye click karein)
    • GitHub kya hai? Ek website jahan programmers apna banaya free software rakhte hain. Jo cheez bahut logon ko pasand aati hai, wo "trending" kehlati hai.
    • Star (★) ka matlab? Jaise YouTube ka like. Jitne zyada stars, utne zyada logon ko pasand aayi.
    • Aapko kuch install karna zaroori nahi. Ye page sirf batata hai ki duniya mein aaj kya naya chal raha hai.
    • Risk label: Kam risk = aam taur par theek. Dhyaan dein = soch samajh kar. Zyada risk = jokhim bhara. Trending ka matlab safe nahi hota. Ye label sirf andaza hai, guarantee nahi.

    Mushkil shabdon ka matlab
    Repo
    Kisi project ka online folder, jisme uski saari files rehti hain.
    README
    Project ka "kaise use karein" wala page.
    Open-source
    Jiska code sabke dekhne ke liye khula hai, aur aam taur par free hota hai.
    Plugin / Skill
    Kisi app ya AI tool mein jodne wala extra feature.
    AI agent
    Aisa AI jo sirf jawab nahi deta, balki khud se kaam bhi karta hai.
    API key
    Ek secret password jo AI jaisi service use karne deta hai. Ise kisi ko na dein.
    Install
    Kisi software ko apne computer ya phone mein lagana.
    Exploit / PoC
    Security ki kamzori dikhane wala code. Aam logon ke liye nahi.

    Safety ke 6 niyam

    1. Ye sirf jaankari hai, salah nahi.
    2. Kuch bhi install karne se pehle uska official page khud padhein.
    3. Risk label sirf andaza hai, security audit nahi.
    4. Anjaan website se command copy karke na chalayein.
    5. Apna password ya API key kisi ko na dein.
    6. Software sirf official GitHub page se hi download karein.
    Zimmedari: Kisi bhi repo ko install ya use karna aapka apna faisla hai. Isse hone wale kisi bhi nuksaan ya haani ki zimmedari is page ya iske banane wale ki nahi hai. Galti ho sakti hai.
