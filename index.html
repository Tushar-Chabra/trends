🔎 Data kahan se aata hai?

Kyun padhein: taaki aap khud check kar sakein ki ye lists kitni sahi hain, aur kahan se aayi hain.

  1. Daily, Weekly, Monthly list: seedha GitHub ki apni Trending page se (github.com/trending), kisi doosri website se nahi. Star number bhi GitHub ka hi hai: is period mein kitne naye stars mile. Source: GitHub.
  2. Yearly list: GitHub yearly list nahi deta. Isliye ye Trendshift (ek doosri trending website) se aati hai. Trendshift apna ranking formula public nahi karta.
  3. Har repo ki details: us repo ke apne README aur code ko padhkar, simple bhasha mein likhi jaati hain. Risk label neeche diye 5 sawaalon se tay hota hai.
  4. Update: Daily aur Weekly roz, Monthly har Monday, Yearly har mahine ki 1 tareekh.

Dhyaan dein: GitHub bhi apni ranking ka poora formula public nahi karta. Ye lists batati hain ki GitHub par abhi kya popular ho raha hai, ye nahi ki kaunsa project sabse achha hai.

🚦 Risk label kaise decide hota hai?

Kyun padhein: taaki aap samajh sakein ki kaunsi repo sirf padhni hai, kaunsi dhyaan se try karni hai, aur kaunsi aaram se.

Ek line mein: Risk label batata hai ki agar aap ise apne computer ya account par chalayein, to kitna nuksaan ho sakta hai. Ye nahi batata ki project achha hai ya bura, ya banane wale ki intention galat hai.

Rasoi wala example: Chammach (Low risk) koi bhi use kar sakta hai. Chaaku (Medium risk) bahut kaam ka hai, par dhyaan se chalana padta hai. Gas ki pipe kholna (High risk) sirf expert kare, warna accident ho sakta hai.

Har repo par ye 5 sawaal poochhe jaate hain

  1. Kya ye kisi software ko andar se kholta hai (reverse engineering), kisi aur ki app, site ya game ki copy banata hai, piracy ya copy-protection (DRM) todta hai, ya hacking tool hai?Haan = High
  2. Kya ise aapke email, payment, GitHub jaise accounts ya poore computer aur files ka control chahiye?Haan = Medium
  3. Kya install ke liye internet se script seedha chalani padti hai, jaise curl … | sh ya irm … | iex?Haan = Medium
  4. Kya file unsigned hai (company ka digital signature nahi, yaani pakka nahi ki file asli hai) ya official page ke bahar se download hoti hai?Haan = Medium
  5. Kya ye kisi website ke rules tod sakta hai (bot-check bypass, scraping), kuch countries mein law ka issue hai (jaise free VPN lists), ya 18+ content hai?Haan = Medium

Rule simple hai: Sawaal 1 ka jawab "haan" = High risk. Sawaal 2 se 5 mein koi bhi "haan" = Medium risk. Sab "nahi" = Low risk.

🟢 Low risk

Matlab: text, learning material ya simple app jo bada access nahi maangta.

Aap kya karein: README padhein, official page se install karein, aaram se try karein.

🟡 Medium risk

Matlab: kaam ka tool, par galat setting se aapka data, account ya paisa risk mein aa sakta hai.

Aap kya karein: test account ya alag folder mein try karein, kam permission dein, script chalane se pehle padhein.

🔴 High risk

Matlab: galat use par legal problem, data chori ya computer kharab ho sakta hai.

Aap kya karein: sirf padhein. Chalana hi ho to expert ke saath, alag (virtual) machine mein.

Ye label kya NAHI hai

  • Security audit ya code scan nahi. Label project ke README aur uske kaam ko padhkar diya gaya andaza hai.
  • Low risk ka matlab zero risk nahi. Har software mein bug ho sakta hai.
  • High risk ka matlab illegal ya bura project nahi. Kai High risk tools security experts aur researchers ke kaam ke hote hain. Label sirf aam user ke liye khatre ko dikhata hai.
  • Label badal sakta hai. Project update hota hai to label bhi badal sakta hai. Final decision hamesha aapka.

📖 Glossary: mushkil words ka matlab
Repo
Kisi project ka online folder, jisme uski saari files rehti hain.
README
Project ka "kaise use karein" wala page.
Open-source
Jiska code sabke dekhne ke liye khula hai, aur aam taur par free hota hai.
Plugin / Skill
Kisi app ya AI tool mein jodne wala extra feature.
AI agent
Aisa AI jo sirf jawab nahi deta, balki khud se kaam bhi karta hai.
API key
Ek secret password jo AI jaisi service use karne deta hai. Ise kisi ko na dein.
Install
Kisi software ko apne computer ya phone mein set up karna.
Exploit / PoC
Security hole (vulnerability) dikhane wala code. Aam logon ke liye nahi.

🛡 6 Safety Rules

  1. Ye sirf information hai, advice nahi.
  2. Kuch bhi install karne se pehle uska official page khud padhein.
  3. Risk label sirf andaza hai, security audit nahi.
  4. Unknown website se command copy karke na chalayein.
  5. Apna password ya API key kisi ko na dein.
  6. Software sirf official GitHub page se hi download karein.
